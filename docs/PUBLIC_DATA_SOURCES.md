# Public data sources for the construction-estimating MVP

Research date: 21 November 2026. Sources were found by web search and by reading pages. No files were downloaded, and no accounts or forms were used.

"Verified" means the page was opened and the data or links were there. "Unverified" means the source was seen only in search results, or the page refused automated fetching.

## Best sources to use first

1. **BVBS GAEB Prüfdateien.** Official certification test files for DA XML 3.1, 3.2 and 3.3, covering phases X81, X82, X83, X84, X86 and X31. AVA vendors test against them, so they are the best regression set for the X8x importer and the arithmetic checks. All direct ZIP links are on one page.
2. **DB InfraGO Muster-LVs.** Full-size template LVs from a public client, each as **PDF, D83 (GAEB 90) and X83**. This is the only source found with the same LV in three formats, which makes it the best test for the GAEB 90 fixed-width parser and the PDF parser against the XML version. The trades are infrastructure (Erdbau, Kabeltiefbau, Massivbrücke), not building work.
3. **Dangl.AVA.Examples GaebFiles.** One small priced project as GAEB 90 `.D86`, GAEB 2000 `.P86` and DA XML 3.2 `.X86`, in German and English. The totals are known (57,550 € net, 68,484.50 € gross), so these work as golden files for the arithmetic checks.
4. **gaeb.de downloads.** XSD schemas for 3.1 to 3.4 beta (for validation), the Fachdokumentation, the 3.1 **Musterdateien** and the Zeitvertrag 3.2 sample files.
5. **oeffentlichevergabe.de OCDS export (CC0)**, used the way the **brsksr/german-construction-tenders-gaeb-api** project does. The national notice service publishes all notices as open data. That project shows real GAEB files can be fetched anonymously from portals under § 41 VgV: its live check reports 347 of 551 notices on supported platforms with a parsed GAEB LV, about 71,000 positions in total. This is the route to a large corpus of real tender LVs.
6. **Austrian LB-HB 023 (BMWET).** A free official library of standard texts for building work, as ÖNORM A 2063 data files plus a PDF per Leistungsgruppe. It suits the catalogue and the matching vocabulary, but the terms forbid modifying it.
7. **DDC CWICR.** About 55,700 work items and 27,700 resources with labour, material and total cost, including a Berlin price track in EUR, as Parquet, CSV or Excel. It is the largest unit-cost base that can be downloaded openly, and it suits the pricing-plausibility checks. Licence: **CC BY-NC 4.0** (non-commercial use only).
8. **Destatis GENESIS 61261-xxxx and Eurostat sts_copi.** Destatis publishes the German building price indices (Baupreisindizes) by building type and type of work; Eurostat publishes EU construction cost indices. Use them to bring dated prices to a common date.
9. **pyGAEB (MIT), gaebboss (MIT/Apache-2.0) and gaeb-rs (non-commercial).** Reference parsers and writers, each with small test files. gaebboss already turns an X83 plus a price CSV into an X84.
10. **Manufacturer catalogue files.** Dimplex (BMEcat with ETIM 10), Schneider Electric Austria (Datanorm V5 price list) and ABB (Excel price list plus BMEcat). Use them to model the supplier catalogue with real product codes and list prices for the electrical and sanitary trades.

## Caveats

- **Test file licences.** The BVBS Prüfdateien and the gaeb.de Musterdateien have no explicit open licence. gaebboss and gaeb-rs both advise checking the BVBS terms, and gaebboss notes that its larger third-party test corpus may **not be redistributed**. Use these files internally, and check the terms before committing them to a public repository.
- **Non-commercial licences.** DDC CWICR (CC BY-NC 4.0), gaeb-rs (PolyForm Noncommercial) and Austria OpenTender (CC BY-NC-SA) are fine for a hackathon but need a licence for a commercial product.
- **Copyright in standard texts.** STLB-Bau texts (DIN/GAEB), CRB NPK, and BKI or SIRADOS prices are copyrighted and paid. Real tender LVs often contain STLB-Bau text, so storing and redistributing scraped LVs at scale carries copyright risk. The Austrian LB-HB is free to use but must not be modified or resold.
- **Tender documents.** § 41 VgV guarantees free access so that companies can take part in a tender. It is not an open licence to build and publish a corpus. The documents also contain personal data (names of planners and authority contacts, and sometimes bidder data in X84 and X86 files), so anonymise them before sharing. Priced bids (X84) and award files (X86) are almost never public: portals provide X83 and PDF only. For priced data, use the BVBS and Dangl samples and the project's own `Data/` folder.
- **Portal terms and scraping.** DTVP, vergabe.NRW (cosinex VMP) and evergabe.de all have terms of use, and the Autobahn GmbH platform reportedly blocks requests from cloud servers. Rate-limit requests, use a generic client name, and prefer the CC0 OCDS export and the TED API for discovery.
- **Verification gaps.** No ZIP files were downloaded, so the contents of the gaeb.de Musterdateien, the BVBS ZIPs and the DB InfraGO ZIPs were not inspected.
